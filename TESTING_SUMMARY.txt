================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Server won't start"
Solution: Check MONGO_URI in backend/.env
         Verify Node.js installed (node --version)

Problem: "ECONNREFUSED to MongoDB"
Solution: Check MongoDB Atlas cluster is running
         Verify credentials in MONGO_URI
         Check network/firewall access

Problem: "Port 5000 in use"
Solution: netstat -ano | findstr :5000
         Kill existing process or change PORT in .env

Problem: "Empty collections"
Solution: This is normal! Call /api/rockets endpoint
         Server will lazy-seed on first request

Problem: "Timeout waiting for server"
Solution: Increase timeout in test script
         Check for Node.js errors in startup logs

More help: See E2E_TEST_GUIDE.md for detailed troubleshooting
