  Step 3: Open second Command Prompt

    curl http://localhost:5000/api/satellites/25544
  
  Step 5: Test MongoDB directly in third terminal:
    
    mongosh "<MONGO_URI>"
    use orbitopedia
    db.rockets.countDocuments()
    db.satellites.countDocuments()
    db.rockets.findOne()
    db.satellites.findOne()
  
  Step 6: Stop server: Ctrl+C in server terminal

SUPPORT RESOURCES
================================================================================

If Tests Fail:
  1. Read: TESTING_SUMMARY.txt (common issues)
  2. Read: E2E_TEST_GUIDE.md (detailed troubleshooting)
  3. Check: E2E_VERIFICATION.md (configuration details)

Specific Problems:
  - "ECONNREFUSED": MongoDB offline - Check Atlas console
  - "Port 5000 in use": Kill process or change port
  - "Empty collections": Normal - lazy seed pending
  - "MONGO_URI not found": Verify backend/.env exists

Debug Commands:
  - Check Node: node --version
  - Check mongosh: mongosh --version
  - Test MongoDB: mongosh "<MONGO_URI>" --eval "db.version()"
  - Find port use: netstat -ano | findstr :5000
