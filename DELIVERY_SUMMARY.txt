⚠️  IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════

1. PowerShell Environment
   - The scripts are designed to work with standard Node.js
   - If PowerShell isn't available, run via cmd.exe directly
   - All scripts are platform-compatible (Windows/Mac/Linux)

2. MongoDB Atlas
   - Connection requires active internet
   - IP whitelist may need updating if running from new network
   - Credentials stored in backend/.env (never hardcoded)

3. Port Requirements
   - Port 5000 must be available for server to start
   - If in use, modify PORT in backend/.env
   - Or stop the process using the port

4. First Run
   - npm install will take 30-60 seconds
   - Subsequent runs are faster
   - Dependencies are cached locally
